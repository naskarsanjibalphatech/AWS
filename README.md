# React + Vite

## Required dependencies

- **Nvm latest**(_if installed run nvm list to check current node version_)
- **Node 22.12.0**
- **Git is required** (_run `git` in terminal_)

## Steps

- Run `git clone https://github.com/Anupam199620/ReportData.git`
- Run `nvm use 22.12.0`
- Run `node -v` to check the version 22.12.0
- Run `npm install`
- Rename .env.example to .env and copy and paste the api host first url
- Run `npm run dev` (open the link in the browser)
